# Data Mining Analysis of Customer Behavior and Seller Performance in Brazilian E-Commerce

This project presents a comprehensive data mining analysis of the **Olist Brazilian E-Commerce** dataset. The main objective is to identify meaningful customer and seller segments using clustering techniques and to predict customer satisfaction using well-known models.

The obtained results demonstrate the applicability of clustering and classification techniques for analyzing real-world e-commerce data.

## Methods

### Clustering
- KMeans
- BIRCH
- Agglomerative Clustering
- Gaussian Mixture Model (GMM)

### Classification
- Logistic Regression
- Random Forest
- XGBoost
